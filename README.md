# 🌸 Iris Flower Classification Using Machine Learning

### CodeAlpha Data Science Internship – Task 1

## 📌 Project Overview

Flowers may look similar, but their measurements can reveal their species! 🌼

This project focuses on building a Machine Learning model that automatically identifies Iris flower species based on four important measurements: sepal length, sepal width, petal length, and petal width.

Using Python and the Scikit-learn library, I developed a **Decision Tree Classifier** to classify flowers into three different species: Setosa, Versicolor, and Virginica.

## 🎯 Project Objectives

- Explore and understand the Iris dataset.
- Perform data inspection and visualization.
- Split the dataset into training and testing sets.
- Build and train a Decision Tree Classification model.
- Evaluate model performance using accuracy, precision, recall, F1-score, and a confusion matrix.
- Predict the species of a new Iris flower using the trained model.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## 📊 Model Performance

The Decision Tree Classifier achieved **100% accuracy on the 30 test samples** in this particular train-test split.

The model correctly classified all three Iris species in the test set.
